# Deflate one-shot decode vs libdeflate, 2026-11-09

First current-source Deflate decode matrix. The earlier
[decode status](decode-optimization-status.md) table carries 2026-11-01/02
epoch ratios and must not be read as current-head rankings; this note replaces
its Deflate decode row.

## Protocol

- Zig 0.16.0 `ReleaseFast`, `x86_64-linux-gnu`, `skylake+pku+sgx`; Intel Core
  i7-10700K; logical CPU 15 pinned with `taskset`.
- Frames are generated by system zlib 1.3 at levels 6 and 9 (raw Deflate,
  `windowBits = -15`).
- Vort uses one-shot `decodeRawDeflate`; the reference uses
  `libdeflate_deflate_decompress` from system libdeflate 1.10.
- Twelve Silesia sources at 64 KiB and 1 MiB prefixes; three invocations per
  row; per-row medians. Each invocation takes the best of five internal rounds.
- Reproduce with `zig build run-deflate-reference-bench -- --input FILE
  --name NAME --level LEVEL --iterations N`.

## Result

`reference_over_vort_time` is libdeflate time divided by Vort time; values below
one mean Vort is slower.

| Level | Prefix | Geometric ref/Vort | Vort slower |
| --- | --- | ---: | ---: |
| 6 | 64 KiB | 0.8890 | 1.12x |
| 6 | 1 MiB | 0.9391 | 1.06x |
| 9 | 64 KiB | 0.8898 | 1.12x |
| 9 | 1 MiB | 0.9359 | 1.07x |
| all 48 rows | | **0.9131** | **1.10x** |

Weakest rows: `nci.64k` L6 0.7823, `nci.64k` L9 0.8208, `mr.64k` L9 0.8499,
`mozilla.1m` L9 0.8601, `mozilla.1m` L6 0.8641, `reymont.64k` L6 0.8662.

Strongest rows: `nci.1m` L9 1.1466 and `nci.1m` L6 1.1364 (Vort is 14% faster
than libdeflate), `xml.1m` 0.9693/0.9700.

Profiles of `nci.64k` L6 put about 46% of Vort decode time in
`deflate.semantic.linear_entry.aligned` including its `memcpy` share, 3.6% in
`decodeRawAutoWithDictionaryFromReader`, and 3.3% in dynamic literal/distance
table construction. The remaining gap is inside the semantic entry loop and the
small-frame fixed costs, not in wrapper or checksum work.

## Next

- The 64 KiB rows are the weak group; table build and the semantic entry loop
  dominate. The prior status note already rejected table shape, speculation,
  cursor, storage and layout experiments, so a new Deflate win needs a
  structural change with new evidence.
- Brotli decode is the next unmeasured current-source decode surface.

## Update: inline wide non-overlap copies (2026-11-10)

Non-overlapping matches longer than 16 bytes fell through to a
runtime-length compiler-rt `memcpy` (7.5% of `nci.64k` L6 decode); a
bounded fixed-width vector copy (`shortcopy.copyWide`, up to 258 bytes
under the linear loop's headroom guarantee) replaced it. The 48-row
paired A/B measured 0.9838 new/old (-1.62%, bootstrap CI
[-2.82%, -0.68%]); see the
[wide-copy note](deflate-wide-copy-20261110.md). Rerunning the
libdeflate 1.10 reference matrix:

| Level | Prefix | Geometric ref/Vort | Vort slower |
| --- | --- | ---: | ---: |
| 6 | 64 KiB | 0.9135 | 1.09x |
| 6 | 1 MiB | 0.9418 | 1.06x |
| 9 | 64 KiB | 0.9109 | 1.10x |
| 9 | 1 MiB | 0.9388 | 1.07x |
| all 48 rows | | **0.9261** | **1.08x** |

The full-matrix ratio moves 0.9131 -> 0.9261. Weak rows improve most:
`nci.64k` L9 0.8208 -> 0.9287, L6 0.7823 -> 0.8742; `nci.1m` remains
ahead of libdeflate (1.14x). Raw rows:
[matrix-post-wide.csv](data/deflate-decode-current-20261109/matrix-post-wide.csv).

## Update: unlikely branch hints on exceptional/secondary paths (2026-11-10)

A branch-miss profile of `nci.64k` L6 showed the literal exceptional-flag
and distance primary/secondary tests among the hottest mispredicts in the
semantic linear loop. Marking both slow paths `@branchHint(.unlikely)`
lays out the common primary-table path without cold-path interleaving.
The 48-row five-round paired A/B measured 0.9817 new/old (-1.83%,
bootstrap CI [-2.35%, -1.32%]); see the
[branch-hint note](deflate-branch-hint-20261110.md). A separate
table-base-pinning experiment (locals for the semantic lookup arrays)
measured 0.9998 and was rejected as neutral. Rerunning the
libdeflate 1.10 reference matrix:

| Level | Prefix | Geometric ref/Vort | Vort slower |
| --- | --- | ---: | ---: |
| 6 | 64 KiB | 0.9294 | 1.08x |
| 6 | 1 MiB | 0.9582 | 1.04x |
| 9 | 64 KiB | 0.9315 | 1.07x |
| 9 | 1 MiB | 0.9561 | 1.05x |
| all 48 rows | | **0.9437** | **1.06x** |

The full-matrix ratio moves 0.9131 -> 0.9261 (wide copy) -> 0.9437.
`nci.64k` L9 reaches 0.9930 (near parity) from 0.8208 at session start;
`nci.1m` extends its lead to 1.1595. Raw rows:
[matrix-post-branch-hint.csv](data/deflate-decode-current-20261109/matrix-post-branch-hint.csv).
