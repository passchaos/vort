# Deflate one-shot decode vs libdeflate, 2026-11-09

First current-source Deflate decode matrix. The earlier
[decode status](decode-optimization-status.md) table carries 2026-11-01/02
epoch ratios and must not be read as current-head rankings; this note replaces
its Deflate decode row.

## Protocol

- Zig 0.16.0 `ReleaseFast`, `x86_64-linux-gnu`, `skylake+pku+sgx`; Intel Core
  i7-10700K; logical CPU 15 pinned with `taskset`.
- Frames are generated by system zlib 1.3 at levels 6 and 9 (raw Deflate,
  `windowBits = -15`).
- Vort uses one-shot `decodeRawDeflate`; the reference uses
  `libdeflate_deflate_decompress` from system libdeflate 1.10.
- Twelve Silesia sources at 64 KiB and 1 MiB prefixes; three invocations per
  row; per-row medians. Each invocation takes the best of five internal rounds.
- Reproduce with `zig build run-deflate-reference-bench -- --input FILE
  --name NAME --level LEVEL --iterations N`.

## Result

`reference_over_vort_time` is libdeflate time divided by Vort time; values below
one mean Vort is slower.

| Level | Prefix | Geometric ref/Vort | Vort slower |
| --- | --- | ---: | ---: |
| 6 | 64 KiB | 0.8890 | 1.12x |
| 6 | 1 MiB | 0.9391 | 1.06x |
| 9 | 64 KiB | 0.8898 | 1.12x |
| 9 | 1 MiB | 0.9359 | 1.07x |
| all 48 rows | | **0.9131** | **1.10x** |

Weakest rows: `nci.64k` L6 0.7823, `nci.64k` L9 0.8208, `mr.64k` L9 0.8499,
`mozilla.1m` L9 0.8601, `mozilla.1m` L6 0.8641, `reymont.64k` L6 0.8662.

Strongest rows: `nci.1m` L9 1.1466 and `nci.1m` L6 1.1364 (Vort is 14% faster
than libdeflate), `xml.1m` 0.9693/0.9700.

Profiles of `nci.64k` L6 put about 46% of Vort decode time in
`deflate.semantic.linear_entry.aligned` including its `memcpy` share, 3.6% in
`decodeRawAutoWithDictionaryFromReader`, and 3.3% in dynamic literal/distance
table construction. The remaining gap is inside the semantic entry loop and the
small-frame fixed costs, not in wrapper or checksum work.

## Next

- Brotli decode is the next unmeasured current-source decode surface.
