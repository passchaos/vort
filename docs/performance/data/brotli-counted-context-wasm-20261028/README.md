# Counted-context Wasm correctness archive

This package preserves the final counted-context Wasm correctness epoch on
2026-10-28 (Asia/Shanghai), using Zig 0.16.0 and Node v26.10.0. The public
q8/generic candidate module and compressed baseline generate identical full
14,362-byte wires from a 65,536-byte input. Candidate counters are four exact
evaluations and two linked emissions. No throughput or memory interpretation
is attached to the archived timing fields.

| File or directory | Contents |
| --- | --- |
| `evidence.json` | Frozen artifact identities, compiler/target/stack settings and expected witnesses |
| `source-manifest.json` | Git base, tree identity, all overlay hashes and unchanged reference hashes |
| `sources/overlays.tar.xz` | All 21 changed/untracked source files captured for this implementation |
| `sources/base-references.tar.xz` | 18 unchanged files from the pinned base, including library/module roots, build definitions and relevant reference helpers |
| `modules/candidate.wasm.xz` | Exact current Wasm module, compressed losslessly with XZ |
| `modules/baseline-ci.wasm.br` | Original Brotli-compressed baseline module used by CI |
| `wires/` | Complete input and both full wires, compressed losslessly with XZ |
| `wire-manifest.json` | Golden-byte origins and raw hashes; this epoch's replay compares all newly generated bytes |
| `gates/` | Frozen Wasm gate, independent v1/v2 profile validator and its smoke tests |
| `profiles/` | Original v2 native report, original independent gate output and all three complete inputs |
| `logs/` | Compressed main completion log and archive replay log with explicit exit status |
| `observed-exits.json` | Attribution of the main gate observation and archive validation exits |
| `replay-summary.json` | Successful frozen replay and independent validation of nine native profile runs |
| `source-restore-result.json` | Successful restoration and verification of the 21 overlays |
| `SHA256SUMS` | Hashes of every stored file except the checksum list itself |

The source manifest includes the counted writer, weighted payload, prepared
literal/common storage, candidate group, trace modules and tests, Wasm probe,
JS gate, profile producer/readers, and contemporaneous memory-probe source
overlays. Memory-probe sources are retained as part of the frozen source epoch;
this package contains no memory measurement result.

From this directory, replay the frozen artifacts without compiling source:

```sh
python3 replay.py --output /tmp/vort-counted-context-replay
```

The output directory must be empty. The script verifies package hashes and
per-file source archive manifests, runs exactly one Node comparison against
the compressed baseline, compares newly generated input/wires with preserved
full bytes, and validates the complete native v2 reports using restored input
paths. It records explicit process exits and a machine-readable summary. CPU
affinity defaults to `0,1,3-9,11-15` and may be overridden with `--cpus`.

The original profile gate also checked the native producer executable SHA
against report provenance before archiving. Replay checks saved report/input
and event identities. The native producer executable is not included; its
identity and original successful check remain recorded in
`observed-exits.json` and `profiles/final-stage-original-gate.json.xz`.

Source restoration requires a Git repository containing base commit
`289110eb515edf7af24a5a72d88c80bfc164b9d8`:

```sh
python3 restore_sources.py --repo /path/to/vort --output /tmp/vort-counted-context-source
```

The script exports base `src/`, `tools/` and build definitions, applies the
verified overlays, and checks all manifest entries. The small base-reference
archive is a convenience subset; remaining unchanged dependencies are obtained
from the pinned Git commit. Baseline source provenance is documented in the
adjacent prepared-command Wasm archive.

Optional narrow rebuild commands, matching the main module's ReleaseFast
encoding, Debug record helper and 8 MiB stack, are:

```sh
taskset -c 0,1,3-9,11-15 zig build-obj -ODebug -target wasm32-wasi -fsingle-threaded -Mroot=/tmp/vort-counted-context-source/src/br/encoder/record_optimal_object.zig -femit-bin=/tmp/vort-counted-context-source/record-wasm.o
taskset -c 0,1,3-9,11-15 zig build-exe /tmp/vort-counted-context-source/record-wasm.o -OReleaseFast -target wasm32-wasi -fsingle-threaded -fno-entry -rdynamic --stack 8388608 -Mroot=/tmp/vort-counted-context-source/src/br_prepared_command_distance_wasm.zig -femit-bin=/tmp/vort-counted-context-source/rebuilt.wasm
taskset -c 0,1,3-9,11-15 node gates/wasm-gate.js modules/baseline-ci.wasm.br /tmp/vort-counted-context-source/rebuilt.wasm /tmp/vort-counted-context-rebuilt-wires
```

These optional rebuilds were not executed during archiving. The archived
replay result belongs to the exact frozen Wasm SHA in `evidence.json`.
