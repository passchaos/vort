# Conservative proper-divisor sampling before exact KMP

Predicate: enumerate d from1 while d<=n/d. When n mod d=0, test p=d and p=n/d, accepting only 1<=p<n. Return true if some p passes x[i]=x[(i+n-p) mod n] at i in {0,1,floor(n/3),floor(n/2),n-1}. The result only decides whether to run exact whole-input KMP; it never supplies the expansion period.

No false negatives. Every proper whole-string period p divides n. Either p<=sqrt(n), so it appears as d=p, or its complementary divisor n/p<=sqrt(n) appears and produces p=n/d. For a true period, every valid i has the same residue modulo p as (i+n-p) mod n, since p divides n, so all five sampled equalities necessarily hold. Other passing divisors may cause an earlier true return but cannot suppress KMP. Exact KMP still computes and validates the least whole period, independently of the sampled divisor.

Bounds. d starts at1 and remains positive. The guard d<=n/d avoids d*d overflow; at n<=900000 the body runs at most floor(sqrt(900000))=948 iterations, with949 only reached for the exit check. Both candidate branches must enforce p<n. In particular at n=1, d=1 is visited, but p=d=n is not proper and must not reach sample index1. Returning false immediately for n<2 is exact and does not remove any proper period. This also protects recursive single-byte bases of all-constant periodic inputs. Empty input remains rejected by transformAlloc before the predicate.

For n>=2 all five i are in0..n-1. With 1<=p<n, shifted=i-p for i>=p, otherwise shifted=i+n-p, is equivalent to the modular expression and lies in0..n-1. Even a temporary i+n is at most1799999 for this format bound, within32-bit usize. The sqrt pair may repeat a square-root divisor; this is only redundant work and may be skipped.

Complexity. Divisor scanning is O(sqrt(n)), with at most five short-circuited byte comparisons for each proper divisor occurrence. More precisely it is O(sqrt(n)+5*tau(n)), and duplicate square-root candidates add at most one predicate. A rejected input avoids O(n) KMP; a false positive retains O(n) KMP after the filter. The complete worst-case still includes KMP. Fixed samples can miss a marker or edit, so there is no universal false-positive-rate guarantee on primitive/near-periodic/structured inputs. A900000-byte all-a string with a single X at index128571 is primitive but passes sampled p=1; it must still be rejected by exact KMP. Under no circumstance should the first passing sampled divisor authorize BWT expansion or restrict KMP to that divisor.
