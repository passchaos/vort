# Wide bit addressing evidence

The index records original text files, byte counts and SHA-256 alongside
hashes of deterministic tar.gz bundles. Numeric bit geometry, actual small
reader operations, real large mappings and full codec families are distinct
verification scopes.

Actual TestFn tables and original all-pass aggregates support the 96-entry
stage. Seven shared named tests occur in both artifacts; the execution count
is not a count of newly introduced tests. Original per-test protocol was not
captured for that aggregate; full codec families have separate indexed results.

Original adapter, reference-RSS and fixture failures remain in their reports.
The native mapping gate has two documented single-call repairs, while the x86
mapping gate uses first executions. Sparse mappings have verified header/tail
and extent manifests; no unread whole-file hash is claimed.

Compile source and copied fast-reader dependencies are bound to their actual
ELF/object manifests. Later test-body and unrelated CLI changes are recorded
as separate source epochs. Full source ZIPs, compiler caches and binary
artifacts are not duplicated here; their identities and local paths remain in
archived reports.

The external archive-crypto portability fix is a separate repository commit.
The original untracked content in its main checkout is preserved. Functional
verification and resource observations do not establish competitor performance
leadership. See the [functional baseline](../../wide-bit-addressing-functional-baseline.md).
