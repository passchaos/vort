verified baseline binary. Native runner ELF/cache artifacts are excluded while

identity, raw timing ratios, contract identities and reference decoder records.

archived structured paths and preserves flags, affinity, input identities and
AB/BA order. The main report states the unstable observations and limitations.

preserve the third independent variant. Its own `guard_validation_audit.py`
