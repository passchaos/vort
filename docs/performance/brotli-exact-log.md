# Exact small-count Q8 histogram logarithms

Brotli histogram models now read a compile-time table for integer counts
0–1,024. Every entry is generated by the existing nine-round u128 squaring
algorithm, including its Q9-to-Q8 rounding. Values above 1,024 keep that scalar
algorithm. The retained cache is 2,050 bytes of shared read-only data and adds
no requested heap allocation or per-context table copy.

The implementation is in `encoder/histogram_model/log_q8.zig`, separate from
the generic histogram owner and model assembly. The histogram model continues
to return exactly the same symbol prices, population, entropy and minimum
population costs. Unseen-symbol penalties, saturating totals, context modes,
candidate order, strict ties, parser budgets, allocations and complete-wire
arbitration remain unchanged. This is exact reuse of the current integer model,
not the q8 context splitter's different linear-log approximation.

## Profile and candidate screens

A post-literal-entropy ordinary q10 B32,3 32 KiB diagnostic records 3,689
user-cycle samples and the same 17,859-byte wire. Self-symbol points include
`compiler_rt.memset=21.09%`, standard command writing `17.44%`, joint-context
discovery `11.67%`, adaptive literal splitting `6.18%` and histogram aggregation
`3.28%`. The retained report disables inline/source resolution, so no precise
logarithm percentage or memset caller attribution is claimed.

The code repeatedly computes histogram logarithms in joint mode choice/tree
assignment, adaptive split iterations, entropy feedback and the 136 possible
segments of the 64 KiB stream grid. Three exact lookup sizes were screened at
five ordinary configurations: B32 q10 32 KiB, Mozilla q10 32/64 KiB, NCI q10
64 KiB and Dickens q11 64 KiB. Three serial sweeps cover 60 processes.

| Table limit | Read-only bytes | Candidate / baseline time |
| --- | ---: | ---: |
| 1,024 | 2,050 | `0.982988` |
| 4,096 | 8,194 | `0.987282` |
| 16,384 | 32,770 | `0.983606` |

An alternative memoizes the preceding nonzero count's logarithm inside each
model construction. It adds no table and reuses equal counts across zero cells.
A separate 45-process screen gives `0.981655` for the 1K table and `0.992235`
for that memoization. These clocks are exploratory and excluded from the
broader final result.

## Ordinary public API matrix

Zig 0.16.0 LLVM ReleaseFast, Linux x86-64/Skylake, Intel i7-10700K, one codec
thread pinned CPU 2. The baseline is the preceding budgeted literal-entropy
increment. Four serial alternating version-order sweeps compare baseline,
1K table, 4K table and adjacent-count memoization over 44 configurations,
giving four samples per version/case and 704 processes. The public allocating
API receives generic mode, default window16 and no HQ overrides. Each process
does an untimed startup encode/decode, one timed encode, then complete-wire
comparison and free outside timing.

The 1K table is retained. Real-file encode time falls 2.01% by the measured
geomean; B32 q10/q11 points are `0.970417/0.955344`, and Mozilla q10/q11
32/64 KiB points are `0.975889/0.975859/0.977310/0.975910`. All complete wires
remain equal across every version and sweep.

Regressions remain in the raw result: q10 MR 64 KiB is `1.008745` with 1/4
paired wins; q2 random 32 KiB is `1.023994` with 0/4 wins; the largest point
is q11 random 32 KiB at `1.026218` with 2/4 wins. The larger 4K table regresses
all four NCI q10/q11 32/64 KiB cases, with the q10 32 KiB point `1.044499`
losing all four pairs. Memoization gives no broad gain. The 16K table remains
an exploratory candidate only. These point estimates do not establish
statistical significance or all-platform performance; call sites without the
histogram model are controls, not evidence of faster logarithms.

## Exactness and resources

Independent bit-squaring reference contracts test 69,827 input values against
all three tables: `0…65536` exhaustive, all `2^k±1` boundaries, u32/u64 limits
and 4,096 random u64 values. The 209,481 comparisons include Q9 odd/even
rounding and 173 rounded carry cases. Fifty-seven consistent histograms at
alphabets 24/64/256/704 compare all model fields against an independent baseline,
including empty/sparse/extreme counts and legal totals above u32. Four candidates
give 228 model comparisons. Eight adaptive splitter cases give 32 complete
plan comparisons, five owned and three null.

Those contracts pass native Debug/ReleaseFast, 32-bit x86 Debug and actual
wasm32-wasi ReleaseFast. The retained library's histogram suites pass 20/20
in Debug and ReleaseFast, and standalone retained x86/Wasm suites pass 9/9.
The public literal-entropy contracts still pass after the lookup is installed.
An independent baseline/current comparison over all 24 public real-file
q10/q11 configurations preserves full wires, requested peaks, exact-cap success
and zero final live requested budget.

Every current timed wire signature matches one of the preceding increment's
44 final configurations, whose frozen streams were externally decoded with
libbrotli 1.2.0 and destination guards. The package verifies the old 88 file
identities and binds the current 704 signatures to the 44 prior-final wires.
The current baseline is that prior final, not the older stored baseline.
No new external decoder execution is claimed for these unchanged bytes.

The final `zig build -j2 test-br-total-memory check check-wasm --summary all`
gate exits 0 at 215/215 steps and 69/69 total-memory tests; CLI help exits 0.
The source and module identity checks, final build completion and independent
frozen reductions are in [the evidence package](data/brotli-exact-log-20261031/).
Compile checks do not imply execution of every repository test.

An isolated next-step boundary probe also confirms an existing fixed-price
LZ77 gap: a caller window of 32,769 reaches index 32,769 in a distance table of
length 32,769 and panics in Debug. This is independent of the histogram cache
and is recorded as a failing diagnostic, not a passing gate. The subsequent
[fixed-window validation increment](../formats/lz77-optimal-windows.md) rejects
that unsupported window before parsing. Internal Brotli,
DEFLATE and Zstd fixed-price callers currently clamp/validate that window to
32 KiB; the repaired generic entry points preserve supported plans and the
wider caller-priced model.

The full deflate/zstd/brotli goal remains active. Remaining literal-only costs
include histogram clearing, candidate preparation and full wire/tree work;
next changes should establish their exact call attribution before changing
layouts or lifetimes. Native Brotli command/distance pricing and the measured
ratio gaps remain separate work.
