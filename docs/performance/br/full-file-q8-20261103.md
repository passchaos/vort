# Full-file Brotli q8 comparison, 2026-11-03

This screen compares Vort q8 with the system libbrotli 1.0.9 reference on six
Silesia files. Both encoders use quality 8, generic mode and an actual window
of 16 bits; `parameters_match=true` for every row. Inputs are truncated to
8 MiB so the screen stays bounded.

Host: Intel Core i7-10700K, 16 logical CPUs, one codec thread. Vort is Zig
0.16.0 `ReleaseFast`, GNU x86-64, `skylake+pku+sgx`. Reference Brotli is the
system `libbrotlienc.so.1.0.9` loaded through `tools/br/libbrotli_runtime.zig`.

Size ratios are Vort/reference encoded bytes. Throughput ratios are
Vort/reference throughput, or `reference_ns/vort_ns`; values below one mean
Vort is slower. The earlier "Time ratio" table labels were incorrect.

| Case | Input bytes | Vort q8 bytes | Reference bytes | Size ratio | Throughput ratio |
| --- | ---: | ---: | ---: | ---: | ---: |
| dickens | 8,388,608 | 3,028,223 | 2,998,227 | 1.0100 | 0.2777 |
| ooffice | 6,152,192 | 2,918,595 | 2,959,535 | 0.9862 | 0.2638 |
| osdb | 8,388,608 | 2,741,829 | 2,767,765 | 0.9906 | 0.2919 |
| sao | 7,251,944 | 5,002,015 | 5,227,559 | 0.9569 | 0.3196 |
| xml | 5,345,280 | 639,005 | 599,486 | 1.0659 | 0.3714 |
| x-ray | 8,388,608 | 5,327,621 | 5,951,015 | 0.8952 | 0.1808 |

Geometric means:

| Path | Size ratio | Throughput ratio |
| --- | ---: | ---: |
| Vort q8 planned | 0.9828 | 0.2777 |
| Vort lazy | 1.0455 | 0.8294 |
| Vort ratio | 0.9803 | 0.2801 |

Vort q8 is 1.7% smaller than reference q8 geometrically, but 3.6 times slower.
X-ray is 10.5% smaller at 5.5 times reference time; XML is 6.6% larger at 2.7
times reference time. The lazy path is 4.6% larger and 1.2 times slower; the
ratio path is 2.0% smaller and 3.6 times slower. This identifies q8 encode
speed, especially for text/XML and binary x-ray, as the next concrete gap. It
is not a leadership claim: mozilla, nci, webster, samba, mr and reymont are
not in this bounded screen.

## Reproduction

```sh
zig build run-br-planned-encode-bench -- \
  --path ~/Work/corpora/silesia-20261025/files/xml \
  --limit 8388608 --iterations 1 \
  --planned-quality 8 --quality 8 --reference-lgwin 16
```

hashes, reference version, provenance and per-row timing.
