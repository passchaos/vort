# Deflate semantic-loop token distribution, 2026-11-14

The 2026-11-12 reader screens concluded that another register-lifetime or
code-layout experiment must be preceded by actual payload-path
classification. This package measures the token shapes of the four
64 KiB fixtures that dominate the current cold decode matrix, using a
read-only counting parser layered on the public `BufferedBitReader` and
Vort `HuffmanTable`; production codec code is unchanged.

## Method

`tools/decode/token_probe.zig` rebuilds each dynamic block's code-length,
literal and distance Huffman tables from the frozen wire, then walks every
symbol and counts:

- literal vs match tokens and the literal share;
- match length histogram (3..258);
- distance histogram (1..32768).

Every probe first runs `decodeRawDeflateAlloc` and compares the complete
output against the frozen plain input, so a counting error cannot publish a
distribution for a wire Vort decodes incorrectly. The probe is a diagnostic
tool, not a production benchmark; no production source file changed.

Inputs are the pinned Silesia 64 KiB fixtures from
`/tmp/vort-decode-baseline-20261114/full/fixtures`, generated by zlib
levels 6 and 9 and independently validated by the decode matrix. Raw output
files in this directory retain the exact probe stdout.

## Consequences for the next optimization

1. There is no single dominant token shape. Reymont and mr favor short
   matches with short distances, nci adds a long-match/long-distance mode,
   and mozilla is literal-heavy with the shortest copies. A one-shape fast
   path cannot cover the matrix.
2. The semantic loop's four-entry literal preload (single, double, triple,
   quadruple literal chains) is well matched: literal shares of 0.37..0.62
   keep those chains hot on every fixture.
3. Distance handling splits clearly: mozilla/mr stay mostly under 32 while
   nci routinely reaches 70..242. The existing 12-bit non-overlap split
   already routes the deep-distance shape separately; a generic entry
   rewrite that enlarges its distance state would tax the short-distance
   majority for a minority path.
4. A safe next experiment must reduce carried state on the short
   match/short-distance path without changing the nci deep-distance route
   or the literal preload chain. The rejected descriptor and OR56 refill
   trials both failed because they added state instead of removing it.

These counts are payload evidence for prioritization, not throughput
results. Any candidate still needs the paired 72-row matrix and the 0.98x
control floor before adoption.
